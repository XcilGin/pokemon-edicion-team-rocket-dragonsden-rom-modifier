口袋妖怪西班牙火箭队ROM修改器
——百度贴吧 祖鲁桃源

使用方法
1. 双击“点我打开修改器.bat”。
2. 浏览器打开后点击“打开 ROM”，选择 .gba 文件。
3. 在“宝可梦”或“招式”页面修改需要的内容。
4. 在“保存”页面点击“保存副本”，原 ROM 不会被覆盖。

可修改内容
1. 宝可梦：六项种族值、属性 1、属性 2、普通特性 1、普通特性 2、隐藏特性。
2. 招式：威力、命中率、PP、属性、分类、优先级、二级效果概率、目标范围。

项目文件
1. 点我打开修改器.bat：双击启动入口。
2. app：修改器网页程序。
3. app\data\catalog.json：宝可梦、招式、属性、特性列表数据。

注意事项
1. 工具适配当前西班牙火箭队底版，其他 ROM 可能无法打开。
2. 工具修改 ROM 文件，不修改存档文件。
3. 电脑需要安装 Python，Windows 版 Python 或 py 启动器均可。
