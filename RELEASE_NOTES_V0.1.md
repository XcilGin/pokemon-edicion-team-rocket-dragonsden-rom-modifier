# V0.1 发布说明

——百度贴吧 祖鲁桃源

English display name: Pokémon Edición Team Rocket (DragonsDen) ROM Modifier

## 中文

V0.1 是第一版公开发布版本，面向新手用户制作。

封装包已更新启动器兼容性：双击启动时会显示启动过程，中文入口不可用时可使用 `start.bat`。

本版包含：

- 本地网页修改器
- 双击启动脚本
- 宝可梦种族值、属性、特性编辑
- 招式威力、命中率、PP、属性、分类、优先级、二级效果概率、目标范围编辑
- 保存前修改清单
- 修改后 ROM 副本下载

本版不包含：

- ROM 文件
- 存档修改功能
- 底层偏移、十六进制、脚本级修改功能
- 捕获率、努力值奖励、基础经验、携带道具、蛋组、成长速度、孵化周期、默认亲密度、性别比例编辑
- 招式标记编辑

## English

V0.1 is the first public release. It is designed for beginner users.

The packaged launcher has been updated for better compatibility. It now shows startup status, and `start.bat` is available as a fallback launcher.

Included in this version:

- Local browser-based ROM modifier
- Double-click launcher script
- Pokemon base stat, type, and ability editing
- Move power, accuracy, PP, type, category, priority, secondary effect chance, and target editing
- Change summary before saving
- Modified ROM copy download

Not included in this version:

- ROM files
- Save file editing
- Raw offset, hexadecimal, or script-level editing
- Catch rate, EV yield, base EXP, held item, egg group, growth rate, egg cycle, base friendship, or gender ratio editing
- Move flag editing
